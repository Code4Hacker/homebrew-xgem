# Code4Hacker Xgem

## How do I install these formulae?

`brew install code4hacker/xgem/<formula>`

Or `brew tap code4hacker/xgem` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "code4hacker/xgem"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
